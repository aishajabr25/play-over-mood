# Play Over Mood UI icons

Original SVG artwork, with 24 × 24 view boxes and rounded brown outlines.
Palette: sunlit blue #C9ECFA, green #DEEAD8, honey #EAD9A6, brown #4B3A2F.
Open `preview.html` to see the complete set. Existing PWA PNGs stay in the parent folder.

Use anywhere: `<img src="icons/ui/water.svg" width="24" height="24" alt="Water">`.
For decorative icons beside an existing label, use `alt=""`.
`manifest.json` maps the site's existing emoji keys to SVG filenames.
`../../icons.js` renders those keys in the interface, including dynamically loaded content.
Stored habit identifiers and records keep their existing keys. User posts, replies,
names, captions, mission text and editable fields are excluded from rendering.
Native select options use plain text labels because they do not support SVG images.

These assets are part of the Play Over Mood project and can be edited individually.
